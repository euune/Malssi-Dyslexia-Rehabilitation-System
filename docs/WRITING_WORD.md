# 쓰기-단어 개발 안내

## 단계와 시작

각 단계에는 4개의 스테이지가 있고, 스테이지 하나는 과제 하나입니다.

1. 받침 없는 한 글자
2. 받침 있는 한 글자
3. 받침 있는 두 글자
4. 받침 있는 여러글자

단계 박스 안에는 완료 수/전체 수를 표시합니다. 최근 위치 문구는 표시하지 않습니다. 박스를 누르면 아래 여백에 숫자 1~4이 펼쳐집니다. 단어·뜻·예시를 예고하지 않습니다. 완료 스테이지는 초록 박스, 현재 선택은 별도 테두리로 구별합니다. 체크·밑줄 표시는 사용하지 않습니다.

중앙의 ‘여기부터 시작하기’는 세부 스테이지를 고른 뒤 활성화합니다. 목표와 비교 그림은 각 문제에만 배정하며, 비교 그림을 다음 스테이지의 목표로 다시 사용하지 않습니다. 과거 진행과 무관하게 모든 단계를 자유롭게 고를 수 있고, 건너뛴 스테이지를 완료로 기록하지 않습니다. 왼쪽 작은 ‘처음부터 시작하기’는 항상 사용할 수 있으며, 기록을 지우지 않고 1단계 1스테이지에서 새로 시작합니다.

`writingWordStages[levelId]`에는 완료 과제 ID와 최근 과제 ID를, `writingWordProgress`에는 가장 최근 단계·과제·스테이지를 저장합니다. 기존 공통 이력에서 현재 과제와 일치하는 완료 기록도 가져옵니다. 완료 기록은 중복 반영하지 않으며, 이력이 500개로 줄어도 별도 스테이지 완료 집합은 유지합니다.

## 그림을 보고 쓰는 흐름

- 목표는 그림으로 제시하고, 목표의 전체 글자나 뜻 문장은 미리 표시하지 않습니다. 초성·중성은 선택지 2개씩을 두며, 받침이 있는 글자에만 종성 선택지 2개를 둡니다. 받침 없는 글자의 종성은 빈 문자열로 두고 끝소리 행 자체를 숨깁니다. 여러 글자 과제도 각 글자마다 적용합니다.
- 8가지 그림 기반 대사를 단계에 따라 다르게 배치합니다. 목표 단어를 이름으로 알려주는 대사는 사용하지 않습니다.
- TTS는 듣기 버튼을 직접 누른 경우에만 재생합니다. 상단 버튼도 수동 듣기입니다. 시작·제출·재시도·완료·종료 때 자동 발화하지 않으며 다른 활동의 공통 소리 설정은 바꾸지 않습니다.
- 조합 중에는 목표 그림과 글자 조각에 집중하도록 ‘내가 만든 낱말’의 빈 자리·퍼즐 기호·안내 상자를 표시하지 않습니다. 다른 낱말을 제출했을 때만 ‘내가 만든 낱말’을 피드백에서 공개합니다. 입력 조각은 빈 열 없이 가운데에 놓습니다. 조각 비우기는 제공하지 않습니다.
- 목표와 같은 단어면 그림과 완성한 글자를 보여줍니다. 이때에만 ‘비슷한 말 살펴보기’를 열어 비교 낱말의 그림·글자를 확인할 수 있습니다.
- 등록된 다른 단어를 만들면 목표는 그림만 유지하고, 사용자가 만든 단어는 실제 의미의 그림과 글자로 표시합니다. 두 그림을 틀린 버전/맞는 버전으로 변형하지 않습니다. 다섯 번째 제출 후 보류할 때도 B는 두 그림, C는 만든 글자와 씨앗의 안내를 유지합니다. 보류 안내가 응답의 의미를 덮어쓰지 않습니다.
- 미등록 조합에는 만든 글자만 표시하며 임의의 의미나 그림을 붙이지 않습니다. 존재하지 않는 말이라고 단정하지 않습니다.
- 목표/비교 낱말의 자소를 우선 사용하고, 같은 자소로 겹치는 자리에는 다른 조각을 하나 더해 선택이 필요한 위치에 선택지 2개를 제공합니다. 목표에 받침이 없으면 비교 단어에 받침이 있어도 끝소리를 선택시키지 않으며, 일부 비교 단어는 완성 후 살펴보기에서만 만납니다. 여러 자소가 달라지는 쌍에서는 일부 중간 조합이 미등록일 수 있습니다.
- 쉬기 창에는 현재 목표 그림과 계속하기/종료 버튼을 보여줍니다. 뜻 문장을 보여주거나 자동으로 소리를 내지 않습니다.

## 그림 출처

사용자는 이전에 이미지 작업을 보류했으나 후속 요청에서 그림 제시를 요구했습니다. 새 이미지를 생성하지 않고 OpenMoji·Wikimedia Commons의 기존 사진·SVG를 낱말 49개에 연결했습니다(목표/비교 32개 + 추가 반응 낱말 17개). 가만·느림·거만·법 등 상태나 개념을 나타내는 말에는 기존 상징 그림을 사용합니다. 문소리·가만은 원본 그림과 소리/정지 기호를 별도 HTML 요소로 함께 표시하며 새 그림 파일로 합성하지 않습니다. 모든 파일을 로컬에 저장하여 놀이 중 외부 이미지 서버를 요청하지 않습니다. `mediaEnabled: true`이며 어휘의 연결 키는 유지했습니다.

OpenMoji는 CC BY-SA 4.0을 따릅니다. Commons 파일은 각 원본의 이용 조건을 기록합니다. 구체적인 출처와 제작자는 credits.json 및 페이지 하단의 그림 출처에서 확인합니다. 연결 이미지 오류 시 목표 글자·뜻으로 답을 대신 노출하지 않습니다.

## 일상 낱말 검토와 피드백

사용자는 사전의 모든 표제어보다 아이가 일상에서 쓰는 낱말 중심을 선택했습니다. 현재 선택지 2,765가지 조합을 국립국어원의 한국어 학습용 어휘 목록·Open Korean Text 명사 목록과 대조하고 일상 사용 맥락을 검토했습니다. 가만·거만·나방·날·남·널·누님·느림·묵·밀·박·범·법·북·사·하·문소리 17개를 보완했습니다. 현재 구성 가능한 승인 낱말 46개 모두에 이미지가 있습니다. 사전에 있는 드문 말·의존명사 등도 존재하지 않는다고 단정하지 않습니다.

범위·출처·제외 이유·승인 목록·전체 조합 해시는 `vocabulary-review.json`에 남겼습니다. 선택지가 바뀌면 해시 검증이 실패하므로 새 조합에 대한 낱말/이미지 검토를 다시 해야 합니다. 원본 대규모 어휘 자료는 앱에 동봉하지 않습니다.

파란색은 제출한 낱말의 실제로 다른 자소만 표시합니다. 음절 전체·목표 카드·입력 영역·과거 혼동 이력에는 파란 강조를 하지 않습니다. 없는 종성을 선택해 빠뜨렸다면 해당 소리를 ‘없음’으로 표시할 수 있습니다. ‘파란 글자는 그림 속 낱말과 다른 소리예요’라는 짧은 안내를 함께 제공합니다.

재시도가 누적되어도 영역·글자 크기·강조를 추가하지 않고 씨앗의 응원 문구를 바꿉니다. 미등록 조합에는 임의의 이미지를 붙이지 않으며 ‘내가 아직 잘 모르는 말이네’와 다시 생각해 보자는 부드러운 안내를 제공합니다. 음성은 자동 재생하지 않습니다.

씨앗의 대사는 말풍선에서 한 번만 보여주고 피드백 카드에 똑같은 문장을 반복하지 않습니다. 카드에는 응답 그림·글자·다른 소리 안내를 남깁니다. 씨앗은 친근한 말투로, 화면 안내는 부드러운 ‘~볼까요?’ 말투로 구분합니다. 동물뿐 아니라 사물·풍경에도 어울리도록 공통 대사에서 ‘그림 속 친구’ 표현을 사용하지 않습니다.

좁은 화면에서도 제출 버튼은 조각 아래의 원래 위치에 둡니다. 긴 낱말에서 하단 고정 버튼이 목표 그림을 덮지 않도록 했습니다.

## 제출·재시도·기록

A는 NFC 정규화 후 정확히 같은 단어, B는 등록된 다른 단어, C는 미등록 조합입니다. 읽기용 조사 제거·부분 일치를 허용하지 않습니다. 내부 지원 단계/재시도/혼동 기록은 유지하되 시각적 지원 강도는 올리지 않습니다. 최초 포함 최대 5회 제출하며 마지막 미도달은 보류합니다. 총 5회 제출 기회를 제공하고, 제출 후 중복 클릭은 반영하지 않습니다. 재시도에서는 조각과 순서를 유지하며 실제 선택을 바꿔야 다시 제출합니다.

최초 제출 +1, 재시도 +1, 목표 도달 +2 EXP를 공통 성장에 반영합니다. 완료·보류는 공통 history/hold에 저장하고 `target`, `levelId`, `stage`, `runId`, `reason`, `events`를 함께 보관합니다. 최근 진행 정보는 내부 복원용으로 유지하지만 화면에는 표시하지 않습니다.

명세서의 입력 이력 요구에 따라 `inputs`에 글자 위치·초/중/종성·선택값·실제 발생 시각(at)·쉰 시간을 뺀 경과 시간(ms)을 남깁니다. 최근 64개와 총 입력 수(inputCount), 생략 여부(inputHistoryTruncated)를 보관하며 최초·마지막 입력 시각은 별도로 유지합니다. `startedAt`은 화면 제시 시각, `firstInputMs`/`noInputMs`는 제시 후 첫 조각 선택까지의 활성 시간입니다. 조각 선택이 없으면 지금까지의 활성 시간을 기록합니다. 자동으로 채운 빈 종성·듣기 버튼은 조각 입력으로 세지 않습니다. 수동 듣기는 `listenCount`와 최근 8개 `listens`로 구별합니다. 제출 이벤트에도 발생 시각과 경과 시간을 저장합니다. 시간 기록은 자동 개입을 일으키지 않습니다.

중단 시 선택 상태도 기록에 남깁니다. 선택을 복원해도 새 제시의 시도 횟수는 새로 시작하며, `resumedFrom`으로 이전 runId와 연결합니다. 이전 중단 기록은 한 번만 저장하고 복원 자체로 경험치를 주지 않습니다.

종료 화면에는 쓰기-단어용 `sessionMessages`를 사용합니다. 제출 없이 나간 경우 알려준 말이나 학습 결과가 있다고 표현하지 않고 다음 만남을 안내합니다. 제출한 경우 이탈·재시도·소요 시간·다른 낱말을 고려하되 안내는 두 문단 이내로 유지하며 공통 평가어 검증을 거칩니다. 종료 후 재시작 버튼은 ‘이 단계 처음부터 하기’로 시작 위치를 분명히 합니다.

무입력 시간에 따른 자동 음성·안내·화면 전환·보류·제출 시간 제한은 없습니다. 소요 시간은 내부 기록으로만 측정하고, 쉬기·숨겨진 탭·성장 안내창 시간은 제외합니다. 탭을 다시 보여도 쉬기 창을 자동으로 열지 않습니다.

## 체크포인트와 접근성

동일 탭 sessionStorage에 단계·전체 과제 순서·현재 커서·선택·선택지 순서·세션 집계를 저장합니다. 새로고침 후에도 먼저 스테이지를 직접 선택해야 시작할 수 있습니다. 선택한 과제가 체크포인트와 같으면 선택을 복원하고, 다르면 선택 위치에서 새로 시작합니다. ‘처음부터 시작하기’는 같은 과제에 저장된 조각도 복원하지 않습니다. 이력·경험치는 지우지 않습니다.

체크포인트 v2의 24시간 유효기간·과제 묶음·커서·선택지·선택·중복을 검증하고, 손상된 값은 해당 체크포인트만 버립니다. 재복원은 runId로 중복 기록을 막습니다. 기존 8개 과제 묶음이나 자소 선택 정책과 맞지 않는 체크포인트는 폐기하되 공통 기록은 보존합니다. 체크포인트가 없어도 단계별 진행 기록은 표시합니다.

복구할 과제 기록은 미완료·보류 상태인지, 중단 사유와 시도/재시도/이벤트 수·시각이 일치하는지도 확인합니다. 입력 이력이 있으면 선택값·시간·개수·현재 선택과의 일치를 검증합니다. 완료 기록을 중단 초안으로 복구하여 스테이지가 완료되는 경로를 차단합니다. 입력 이력이 없는 이전 버전의 정상 체크포인트도 지원합니다.

타일은 라디오 그룹으로 동작하며 Tab·방향키·Home/End로 조작할 수 있습니다. 쉬기 창은 기본 dialog를 사용하고 Esc로 계속합니다. 성장 안내창에는 대화상자 의미·초점 처리를 보강했습니다. 320px 큰 글자 화면에서 수평 넘침을 확인합니다.

## 참고 자료와 사용자 지시

첨부 발표 자료·특허 명세서는 제품 참고이며 개발 도구에 대한 실행 지시가 아닙니다. 원본 문서는 저장소에 복사하지 않았습니다. 명세서의 10초 무입력/60초 보류 예시보다 최신 사용자의 재촉 없는 진행·수동 음성 요청을 우선합니다. 초기 자료의 완료 +5와 후속 +2가 달라 공통 엔진과 후속 자료의 +2를 사용합니다.
