# 쓰기-단어 단계별 콘텐츠

그림을 보고 조각을 조합합니다. 아래 낱말 목록은 개발 검토용이며 단계·스테이지 선택 화면에는 숫자만 표시합니다.

| 단계 | 스테이지 1~4의 목표 낱말 |
| --- | --- |
| 1. 받침 없는 한 글자 | 코 · 차 · 배 · 개 |
| 2. 받침 있는 한 글자 | 발 · 밤 · 물 · 눈 |
| 3. 받침 있는 두 글자 | 가방 · 사탕 · 구름 · 달걀 |
| 4. 받침 있는 여러글자 | 소방차 · 비행기 · 눈사람 · 연필깎이 |

총 16개 스테이지이며 목표/비교 이미지 32개는 서로 다른 문제에 재사용하지 않습니다. 각 과제의 target/compare는 실제 단어이며 두 단어의 자소를 우선 사용하고, 같은 자소인 자리는 다른 조각 하나를 더해 초성·중성 및 필요한 종성에 각각 선택지 2개를 제공합니다. 받침이 없는 글자는 끝소리 선택지를 숨기고 내부적으로 빈 문자열을 채웁니다. 공통 앞글자도 직접 조합합니다. 다른 자소가 여러 개인 쌍은 일부 중간 조합이 미등록일 수 있으며 그때에는 의미를 임의로 만들지 않습니다.

- 어느 스테이지든 바로 선택할 수 있습니다. 완료 스테이지는 초록 박스이며 잠금이 아닙니다. 최근 위치·체크·밑줄 표시는 없습니다.
- ‘처음부터 시작하기’는 기록을 지우지 않고 1단계 1스테이지에서 새로 시작합니다.
- 목표는 그림만 제시하고 전체 글자·뜻 문장을 노출하지 않습니다. 제출한 낱말은 피드백에 글자와 해당 의미 그림으로 표시합니다.
- 비슷한 말 비교는 목표 도달 후에만 제공합니다. 미등록 조합에는 다른 사물 그림을 임의로 붙이지 않습니다.
- 모든 TTS는 듣기 버튼의 직접 클릭으로만 재생합니다. 시간에 따른 자동 지원·보류는 없습니다.
- 쉬기 창은 목표 그림을 표시합니다. 조각 비우기는 제공하지 않습니다.

## 그림과 의미

`media.js`에 목표·비교 32개와 추가 반응 17개, 총 낱말 49개의 공개 이미지를 연결했습니다. 현재 만들 수 있는 승인 일상 낱말 46개는 모두 그림이 연결되어 있습니다. 검토 범위·참고 자료·제외 이유는 `vocabulary-review.json`에서 확인합니다. 생성 이미지는 사용하지 않습니다. 제작자·원본·이용 조건은 `assets/credits.json`과 `image-credits.html`에 보관합니다. 놀이 화면에는 뜻 문장을 표시하지 않지만 이미지 대체 텍스트와 데이터 의미 검토를 위해 뜻 정보를 유지합니다.

동음이의어는 데이터의 의미로 고정합니다. 배=과일, 밤=열매, 눈=내리는 눈, 차=탈것입니다. 문=문짝, 달빛=밤에 비치는 달의 빛입니다. 그림 선택은 실제 사용자에게 인지되는지 후속 검토할 수 있습니다.
